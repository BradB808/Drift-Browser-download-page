MCP — now available in Drift

Your coding agent
can drive the canvas

Switch on Drift's connector and Claude Code — or any MCP client — can open cards, read the pages already in front of you, and act on them, without ever leaving the terminal.

Runs entirely on your Mac. Nothing is hosted and nothing leaves the machine: the connector listens on 127.0.0.1 alone, and it stays switched off until you turn it on in Assistant → Connections. Read the full guide.

$ claude mcp add --transport http drift http://127.0.0.1:8787/mcp --header "Authorization: Bearer <token>"

Sees your whole canvas

Questions,
answered

Is Drift free?

Yes. Drift is free and open source under the GPL-3.0 license. No accounts, no subscriptions, no upsells.

What is a spatial browser?

A browser that lays your pages out as cards on a zoomable canvas instead of a row of tabs, so your session looks like a map. Read the full explainer.

What does Drift run on?

macOS, on both Apple Silicon and Intel Macs. A Windows build is coming soon.

Does Drift support Chrome extensions?

Yes. Install ad blockers and other extensions straight from the Chrome Web Store; their icons live in the Drift toolbar.

Can I use Drift with Claude Code?

Yes. Drift has a built-in MCP connector, so Claude Code or any MCP client can drive your canvas from the terminal. It runs only on your Mac and is off until you switch it on. See how it works.

Does Drift track my browsing?

No. There are no accounts, no sync servers, and no browsing log. Your canvas and bookmarks stay on your machine.

What engine does Drift use?

Chromium, via Electron. Every card is a real sandboxed browser page, so logins, video, and web apps all work like you expect.
